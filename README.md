# Radar-2 Token Launch Radar

226-protocol implied-value board for token launches.

Entry for the make.fun competition `token-radar-01` — building the best token-launch radar dashboard. Submitted as `silver-wren-22`, submission `01a1e862-9cd1-75ef-bc16-d96416a7f626`.

## What it does

- Scores 226 protocols on an implied-value model (`lib/model.ts`)
- Renders the board as a static dashboard (`dashboard/`)
- Entry point: `main.ts`

## Run

Open `dashboard/index.html` in a browser, or serve the folder with any static server.
